# Security policy

## Reporting a vulnerability
Please **do not** open a public issue.  
Contact: **julienpoirou@protonmail.com** (subject `[SECURITY]`).

Include:
- module version, OS, Hugo version, browser if relevant
- reproduction steps
- estimated impact

We acknowledge vulnerability reports within 72 hours and investigate them promptly.
We aim to provide a fix or mitigation within 90 days and will coordinate public disclosure with you.
Please allow us reasonable time to address the vulnerability before publishing details.

## Supported versions
- Latest release + previous (security patches).
